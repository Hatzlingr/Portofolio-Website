# Product Requirements Document

## 1. Project Overview

### Project Name
Emerald Portfolio

### Product Type
Personal portfolio website.

### Description
A personal portfolio website that showcases the owner's profile, skills, selected projects, and contact information through a minimalist futuristic interface.

The website is inspired by Green Lantern aesthetics, using an emerald color palette with an interactive transition to a yellow palette.

## 2. Objectives
- Present the owner's profile professionally.
- Showcase technical projects and experience.
- Provide a central destination for GitHub and professional links.
- Create a memorable visual identity.
- Demonstrate frontend development and interaction design skills.

## 3. Target Audience
- Recruiters
- Developers
- Potential collaborators
- Academic and professional contacts

## 4. Core Features

### Hero
- Display the owner's name.
- Display a concise professional introduction.
- Provide links to projects and contact information.
- Feature the interactive orb.

### About
- Introduce the owner.
- Summarize academic and technical interests.
- Communicate professional goals.

### Projects
- Showcase selected projects.
- Display project title, description, technologies, and links.
- Support GitHub and live demo links when available.

### Skills
- Display relevant technical skills.
- Group skills by category.

### Contact
- Provide email and professional social links.
- Include GitHub and LinkedIn links when available.

### Theme Interaction
- Default theme: emerald.
- Alternate theme: yellow.
- Orb interaction changes the global color palette.
- Theme transition should be smooth and visually consistent.

## 5. Non-Functional Requirements
- Responsive across desktop, tablet, and mobile.
- Fast loading.
- Accessible navigation and interactions.
- Readable typography and sufficient contrast.
- Maintainable component structure.
- SEO-friendly metadata.

## 6. Technical Constraints
- Next.js App Router
- TypeScript
- Tailwind CSS
- Motion for animations
- Lucide React for icons
- Vercel deployment

## 7. Out of Scope for Initial Version
- Authentication
- Backend API
- Database
- Admin dashboard
- Blog CMS
- Analytics dashboard

## 8. Success Criteria
- All core sections are implemented.
- Orb interaction works on desktop and mobile.
- Theme changes affect the entire page.
- Website is responsive.
- Production build succeeds.
- Website can be deployed publicly.
