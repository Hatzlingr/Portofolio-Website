=====================================================
MIRRDEV PORTFOLIO - PROFILE PORTRAIT INSTRUCTIONS
=====================================================

To use your personal portrait:
1. Prepare a transparent-background PNG photo of yourself.
2. Recommended resolution: 800 x 1000 pixels (4:5 vertical portrait aspect ratio).
3. Save the file directly as:
   public/images/profile.png

The About section will automatically display your image with the futuristic emerald/yellow lateral contour rim glow!
